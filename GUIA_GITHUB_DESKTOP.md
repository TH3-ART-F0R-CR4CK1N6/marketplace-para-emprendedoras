## 📁 PASO 3: Agregar tu Proyecto

1. En GitHub Desktop, click en **"Add an Existing Repository"**
   (O ve a: File → Add Local Repository)

2. Click en **"Choose..."**

3. Navega a la carpeta:

   c:\All mio\Python projectos goood\Pagina marketplace
